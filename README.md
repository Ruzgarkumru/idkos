# idkOS 1.0.2
## This file will walk you through the process of creating a idkOS user and using idkOS.

> [!NOTE] 
> Note that this project is designed for Linux Mint Xfce, not tested for Mate or Cinnamon.

> [!DISCLAIMER]
> Don't forget to extract the .tar.gz you downloaded before any steps!

1. Setup:
> On your Linux Mint device, run terminal. To run the terminal you can press <kbd>CTRL</kbd> + <kbd>ALT</kbd> + <kbd>T</kbd> at the same time, or search Terminal in the search menu and click the black app icon.
> 
> After running the terminal, confirm that the terminal is running inside the idkOS-1.0.2 folder. If not, type `cd ~/"[the folder that idkOS-1.0.2 is in]"/idkOS-1.0.2`.
> 
> After confirming that its running inside the right folder, type `python3 idkos_setup.py` inside the terminal and complete the setup. If you want to log in as supersys (superaccess user), skip this part.

2. Log into user account:
> (Optional) If you want to log in as supersys, the password will be inside **idkOS-1.0.2/supersys/usrinfo.txt**.
> 
> After the setup is done, type `python3 idkos_user.py` in the terminal, type in the username and the password of the account you want to log into.
> 
> After it shows **@terminal** with your username, type `help` or `apphelp` for available apps and commands.

3. Closing idkOS:
> You can close idkOS by typing `closecli` or by closing the terminal.

*I hope you enjoy this joke mini-OS running inside a terminal :D*
